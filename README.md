# RBF-parameterized level-set inversion

Code accompanying the M.Sc. thesis *Parameterized Level-Set Inversion of Sharp-Boundary Targets Using Radial Basis Functions* supervised by Lindsey Heagy at the University of British Columbia Geophysical Inversion Facility.

The thesis develops a parametric level-set inversion in which the boundary of a subsurface target is the zero contour of a level-set function built from a weighted sum of Gaussian radial basis functions. The inversion solves for the RBF weights rather than for a physical property in every mesh cell, so the recovered model is sharp by construction and the number and shape of the targets do not have to be specified in advance. The method is implemented as a custom mapping in [SimPEG](https://simpeg.xyz) with analytic sensitivities, and demonstrated on three synthetic problems: 2D DC resistivity, 3D muon tomography, and 3D airborne time-domain EM.

## Formulation

The physical property model is a binary partition of the domain,

```
m(x) = m_0 + (m_p - m_0) * H_eps( phi(x; alpha) )
```

with the level-set function

```
phi(x; alpha) = sum_j alpha_tilde_j * exp( -beta_j^2 * ||x - x_j||^2 )
```

where `alpha_tilde_j = (2/pi) * arctan(alpha_j / 2)` bounds the contribution of any single centre, `beta_j` is the dilation parameter of centre `j`, `x_j` are fixed centre locations, and `H_eps` is the C2 regularized Heaviside with smoothing parameter `eps`. The background and target property values `m_0` and `m_p` are treated as free inversion parameters with box bounds, so the inversion vector is `[alpha, m_0, m_p]` of length `N + 2`. The regularization trade-off parameter is `lambda`.

Derivations of the sensitivities are in Chapter 2 of the thesis.

## Repository layout


```
rbf_param_msc_thesis/
  mappings/ 
  parametric_rbf_mapping.py          core implementation (ParametricRBFMapping)
      __init__.py                        replacement init for SimPEG mappings class.
      _parametric.py                     replacement parametric SimPEG mapping class. 
  notebooks/
      chap2/
        dcr_inv_chap2       Two compact conductor hyperparameter results.
      chap3/
        dc_two_block/        Example 1a: two compact conductors
        dc_basement/         Example 1b: depth to basement
        muon/                Example 2: block cave, muon tomography
        helisam/             Example 3: HeliSAM TDEM
  environment.yml
```
The `ParametricRBFMapping` mapping is a subclass of SimPEG's `IdentityMap`. 

## Installation

```bash
conda env create -f environment.yml
conda activate rbf-levelset
pip install -e .
```
Copy-paste `__init.py__` and `_parametric.py` from `mappings` folder into SimPEG's maps folder.


## Examples

| Example | Physics | Mesh (active cells) | RBF centres | Parameters | eps | lambda |
|---|---|---|---|---|---|---|
| Two compact conductors | 2D DC resistivity | 16,000 | 158 (140 core, 18 non-core) | 160 | 1.0 | 0 |
| Depth to basement | 2D DC resistivity | 14,400 | 241 | 243 | 1.0 | 0 |
| Block cave | 3D muon tomography | 46,656 | 878 | 880 | 1.0 | 10, halved every iteration |
| Conductive block | 3D HeliSAM TDEM | 26,912 | 10,000 | 10,002 | 0.1 | 100, halved every 2 iterations |

Each notebook builds the true model, simulates and contaminates the data, sets up the RBF parameterization, runs the inversion, and reproduces the corresponding figures in Chapter 3. Where a smooth L2 inversion is used as a baseline, it is run on the same mesh, survey, and uncertainties.

Runtimes: the 2D DC examples run in minutes on a laptop. The muon example is comparable, since the forward operator is linear. The HeliSAM example requires a full 3D time-domain solve and will run in the order of hours. 

## Muon tomography example: proprietary dependency

The muon forward operator uses a ray-tracing routine provided to the UBC Geophysical Inversion Facility by Patrick Belliveau of Ideon Technologies as proprietary code. **That routine is not included in this repository and the muon notebook will not run without it.**  The notebook is provided so the inversion configuration is documented and so the RBF-specific code paths can be inspected.

The DC resistivity and TDEM examples have no proprietary dependencies and are fully reproducible from this repository.

## Data

All data in this thesis are synthetic and are generated by the notebooks. No field data are included.
